## 👥 ¿Quiénes somos?

Somos **Masters of Code**, un equipo de estudiantes de la **Tecnicatura en Programación de la UTN San Rafael** (Mendoza, Argentina). En este repositorio reunimos todo lo que trabajamos durante el cuarto semestre: ejercicios de clase, proyectos, quizzes y juegos desarrollados en distintos lenguajes.

## 🚀 Cómo usar el repositorio

1. Cloná el repositorio:
   ```bash
   git clone https://github.com/HotCode2025/MastersOfCode-cuarto-semestre.git
   ```
2. Entrá a la carpeta:
   ```bash
   cd MastersOfCode-cuarto-semestre
   ```
3. Instalá las dependencias de Node (si vas a correr algo de la carpeta `Node`):
   ```bash
   npm install
   ```
4. Abrí la carpeta del lenguaje o proyecto que quieras ver y seguí las indicaciones de cada uno.
