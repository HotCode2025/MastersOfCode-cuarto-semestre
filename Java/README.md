## 📖 Sobre esta carpeta

Acá reunimos todo lo que trabajamos en las clases de **Java** durante el cuarto semestre. Practicamos programación orientada a objetos y desarrollamos aplicaciones completas, como un **sistema de gestión de estudiantes** y una **tienda de libros**, primero en Java puro y después con **Spring Boot**, sumando manejo de excepciones y quizzes de repaso.

## 🚀 Cómo ejecutar los proyectos

1. Asegurate de tener instalado el **JDK** (versión 17 o superior recomendada):
   ```bash
   java -version
   ```
2. Abrí el proyecto que quieras ver en tu IDE (IntelliJ IDEA, VS Code o Eclipse).
3. Ejecutá la clase principal (la que contiene el método `main`).

> En los proyectos con Spring Boot, ejecutá la clase marcada con `@SpringBootApplication`.
