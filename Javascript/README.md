## 📖 Sobre esta carpeta

Acá reunimos todo lo que trabajamos en las clases de **JavaScript**. Arrancamos construyendo el cliente de un **e-commerce** con HTML, CSS y JavaScript, y después avanzamos hacia un **proyecto full stack con el stack PERN** (PostgreSQL, Express, React y Node.js).

---
