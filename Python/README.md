## 🚀 Cómo ejecutar los archivos

1. Asegurate de tener **Python 3** instalado:
   ```bash
   python --version
   ```
2. Entrá a la carpeta de la clase que quieras ver:
   ```bash
   cd Python/Clase01
   ```
3. Ejecutá el archivo:
   ```bash
   python nombre_del_archivo.py
   ```

> También podés abrir la carpeta `Python` directamente en **PyCharm** para usar la configuración del proyecto.
